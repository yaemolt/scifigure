# Refined Plan

## 总体构图

- 画布方向：横向
- 建议画布尺寸：`1800 x 1040`
- 左区宽度约 `920`
- 右区宽度约 `660`
- 中间保留 `80~100` 像素缓冲区，避免两侧视觉拥挤

## 左侧流程区

### 布局规则

- 左区顶部放总标题：`LSH Attention Pipeline`
- 五行流程按纵向均匀分布
- 每一行由“行标题 + token 排列”组成
- token 统一宽高，保持强工程图秩序感

### 行内容定义

#### 第 1 行

- 标题：`Sequence of queries + keys`
- token 数：16
- 颜色：白色填充、黑色描边
- 排列：连续等距，无分组空隙

#### 第 2 行

- 标题：`LSH bucketing`
- token 数：16
- 颜色编码：
  - 蓝：bucket A
  - 黄：bucket B
  - 红：bucket C
  - 灰：bucket D
- 排列：位置仍连续，表示仅完成 bucket 赋值

#### 第 3 行

- 标题：`Sort by LSH bucket`
- token 数：16
- 排列：同色 token 连续聚类为 4 段

#### 第 4 行

- 标题：`Chunk sorted sequence to parallelize`
- token 数：16
- 排列：每 4 个 token 为一组，共 4 组
- 组间保留明显空隙
- 每个 chunk 可用浅灰虚框或留白间隔来表达独立计算单元

#### 第 5 行

- 标题：`Attend within same bucket in own chunk and previous chunk`
- 延续第 4 行 chunk 布局
- 连线要求：
  - chunk 内部存在短灰弧线
  - 当前 chunk 与前一 chunk 之间存在少量跨块灰弧线
  - 不使用太粗线条，避免压过 token 本身

### 流程关系表达

- 在左侧流程区边缘增加 4 个向下箭头
- 视觉上明确表达：
  - 输入序列
  - 哈希分桶
  - 排序聚类
  - 分块并行
  - 局部注意力

## 右侧矩阵区

### 布局规则

- 采用 2×2 网格
- 每个矩阵尺寸统一
- 每个矩阵顶部显示子图标题
- 每个矩阵左侧为 `q1~q6`
- 每个矩阵顶部为 `k1~k6`

### 四个子图定义

#### (a) Normal

- 用少量离散深灰或彩色点表示全连接 attention 中非结构化激活
- 保持稀疏、散点感

#### (b) Bucketed

- 形成多个彩色局部块
- 蓝块、黄块、红块分别位于不同局部区域
- 表达哈希分桶后的局部聚类

#### (c) Q = K

- 沿主对角线形成逐渐展开的彩色三角区域
- 突出 query-key 对齐结构

#### (d) Chunked

- 沿对角线形成离散矩形块
- 块与块之间有边界感
- 表达 chunk 范围内局部注意力
