# Visual Spec

## 总体视觉方向

- 论文插图风格
- 工程化、克制、结构清晰
- 用颜色表达语义，不用颜色制造装饰感

## 颜色

- 背景：`#FFFFFF`
- 主文字：`#111111`
- 主描边：`#111111`
- 次级线条：`#8A8A8A`
- 蓝色 bucket：`#8FB3E8`
- 黄色 bucket：`#E9D27A`
- 红色 bucket：`#D98989`
- 灰色 bucket：`#BFC3C8`
- 矩阵空白单元：`#FFFFFF`
- 矩阵基础浅灰：`#F3F4F6`

## 形状规则

- token：直角矩形
- 矩阵单元：正方形
- 外框：细黑线
- 不使用圆角胶囊或强阴影

## 连线规则

- 流程箭头：细灰线，明确方向
- 第五行弧线：灰色曲线，透明度感偏轻，避免遮挡 token
- 不使用粗黑箭头

## 文本规则

- 总标题可略大且加粗
- 行标题与矩阵小标题层级清晰
- 字体以学术论文可接受风格为主
- 不使用夸张字重和高饱和配色标题

## 矩阵表达规则

- (a) 使用离散散点感
- (b) 使用局部彩色方块
- (c) 使用对角三角带
- (d) 使用块状对角矩形
