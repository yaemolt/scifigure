# Intake Summary

- 模式：纯文本需求
- 参考风格图：无
- 外部 PNG / SVG 素材：无
- 输出语言：中文
- 最终目标：生成可导入 `draw.io` 编辑的论文风格示意图 XML

生成一张“Reformer 中 LSH Attention 流程示意图”，版面横向展开，左侧为五层流程结构图，右侧为四个小型注意力矩阵对比图，整体风格接近顶会论文插图。

- 以 `draw.io` 可编辑性优先
- 白底黑线为主，低饱和彩色作为语义点缀
- 左侧需清楚表达五阶段处理链路
- 右侧需清楚表达四种 attention pattern 对比
- 需要像论文中的 Figure 2，而不是商业海报或演示幻灯片
