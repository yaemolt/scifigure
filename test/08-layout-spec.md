# Layout Spec

## 画布

- 尺寸：`1800 x 1040`
- 背景：白色
- 坐标原点：左上角
- 安全边距：左右各 `40`，上下各 `40`

## 版面分区

### 左区：流程图

- 区域范围：`x = 40~960`, `y = 80~980`
- 标题区：`x = 60~420`, `y = 40~80`
- 每一流程行高度约 `120`
- token 区域左缘与行标题左缘对齐

### 右区：矩阵图

- 区域范围：`x = 1040~1760`, `y = 80~980`
- 2×2 网格
- 每个矩阵外框约 `220 x 220`
- 矩阵之间水平与垂直间距约 `80`

## 左区精确布局

### 行标题坐标

- 行 1 标题：`(60, 110)`
- 行 2 标题：`(60, 200)`
- 行 3 标题：`(60, 290)`
- 行 4 标题：`(60, 380)`
- 行 5 标题：`(60, 470)`

### token 排列

- 标准 token 尺寸：`24 x 24`
- 连续排列时水平步长：`32`
- chunk 排列时每 4 个 token 后增加 `36` 的组间空隙

### 行 1 / 行 2 / 行 3

- token 起点：`x = 360`
- 行 1 `y = 100`
- 行 2 `y = 190`
- 行 3 `y = 280`

### 行 4 / 行 5

- chunk 化 token 起点依次为：
  - chunk 1: `x = 360, 392, 424, 456`
  - chunk 2: `x = 520, 552, 584, 616`
  - chunk 3: `x = 680, 712, 744, 776`
  - chunk 4: `x = 840, 872, 904, 936`
- 行 4 `y = 370`
- 行 5 `y = 460`

### 箭头与弧线

- 在左区最左边使用纵向流程箭头连接五行
- 第 5 行中：
  - 每个 chunk 内画 1~2 条短灰弧线
  - 在 chunk 2/3/4 中各增加 1 条连往前一 chunk 的灰弧线

## 右区矩阵布局

### 矩阵位置

- (a) `x = 1080, y = 140`
- (b) `x = 1370, y = 140`
- (c) `x = 1080, y = 500`
- (d) `x = 1370, y = 500`

### 每个矩阵

- 外框尺寸：`220 x 220`
- 单元格：`6 x 6`
- 单元格尺寸：`24 x 24`
- 网格起点为矩阵左上角内缩 `50 x 40`
- 顶部列标签 `k1~k6`
- 左侧行标签 `q1~q6`
