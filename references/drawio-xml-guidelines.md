# Draw.io XML Guidelines

The final XML must be optimized for human editing after import into `draw.io` or `diagrams.net`.

## Priorities

1. editability
2. scientific clarity
3. layout stability
4. style consistency
5. visual fidelity

## Prefer

- editable text nodes instead of flattened text
- independent shapes instead of oversized composites
- adjustable connectors and arrows
- grouping only when it improves manipulation
- simple structures that can be understood and edited quickly

## Avoid

- unnecessary nesting
- decorative structures that block editing
- flattening multiple semantic elements into one object when separation helps editing
- XML tricks that improve appearance but make maintenance harder

## Asset Handling

- keep imported assets identifiable
- preserve reasonable scale relationships
- avoid placements that force unreadable labels or connector tangles
