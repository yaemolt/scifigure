# Style Analysis Rubric

When reference images are provided, document reusable style constraints instead of copying pixels.

## Capture

- palette and contrast strategy
- background treatment
- shape language
- border and container behavior
- arrow and connector style
- text hierarchy
- spacing rhythm
- visual density
- emphasis behavior

## Output Goal

Produce a transferable rule set that can guide:

- `architect`
- `drawer`
- `writer`

## Avoid

- vague adjectives without operational meaning
- full layout decisions that belong to `architect`
- details that reduce `draw.io` editability
