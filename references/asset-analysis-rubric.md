# Asset Analysis Rubric

When reusable `png` or `svg` assets are provided, treat them as semantic inputs and structural constraints.

## Record

- file type
- width and height
- aspect ratio
- transparency condition
- cropping or background issues
- scientific meaning
- role priority
- independence requirement
- scaling constraints

## Output Goal

Give enough guidance for:

- `planner` to understand asset importance
- `architect` to place assets meaningfully
- `xml-drawer` to preserve manageable editing behavior

## Avoid

- making final placement decisions
- rewriting the story around the assets
- treating assets as decorative only if they carry scientific meaning
